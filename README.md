# Матаков Михаил РИС-25-1м
Инфраструктура для предварительной фильтрации текстовых файлов перед их основной обработкой. Единственный доступный извне сервис — file-proxy. При получении HTTP-запроса с файлом, он извлекает текст и отправляет его трём независимым LLM-сервисам. Каждая модель проверяет наличие в файле основных структурных элементов: введения, заключения, списка литературы, а также достаточный объём текста.
На основе полученных вердиктов (good или bad) file-proxy принимает решение: если хотя бы две модели из трёх сказали good, файл считается прошедшим первичный фильтр и передаётся в сервис normocontrol-service для полноценной проверки. В противном случае файл отклоняется.

На ноутбуке не хватает памяти, поэтому вместо трёх LLM работает одна. Модель иногда ошибается и не видит нужные слова.
